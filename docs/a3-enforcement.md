# A3 enforcement handoff

These are actionable **future glint rule specifications**, not implemented rules or claimed enforcement. Aegis's compiler/type checks cover normal typed calls; Zig field access, reflection, raw extraction and foreign paths can bypass them. Admission remains glint's responsibility: resolve declarations, count and review family hits, report unsupported coverage, report first, gate only after independently demonstrating almost no false alarms. No glint source or book is changed by A3.

Operation identities are the declarations in `src/int.zig`, `src/id.zig`, `src/units.zig` and `src/assert.zig` at the adopting commit. Tags carry no runtime metadata. Every suppression must contain a nonempty written reason, identify the rule and belong to one of: danger absent, design removes the bug class, measured hot loop with validated boundary, safe-type internals, C/OS boundary. Count and review suppressions; a bare `safe`, `performance`, or `trusted` is insufficient. A measurement exception links enduring repo evidence and names the validated bounds. This document admits no blanket exemption.

| Proposed rule | Raw pattern and bug class | Accepted replacement and examples | Permitted written-reason examples |
|---|---|---|---|
| `aegis.checked-arithmetic` | Resolved scalar `+`, `-`, `*`, `/`, `%`, left shift on sizes, capacities, offsets or exhaustion-sensitive counters where overflow/div0/invalid shift remains possible in ReleaseFast. Report unknown domain flow rather than guessing from every integer. Native wrapping is never silently treated as safe. | `try int.Checked(usize).init(count).mul(width)`; `try checked.shl(shift)`. `Saturating` is accepted only where a declared clamp policy makes exhaustion harmless. | `safe: checked-arithmetic: safe-type internals; @addWithOverflow implements the public all-mode error`; `safe: checked-arithmetic: measured hot loop; docs/kernel.md proves count <= 4096 and width <= 16 at entry`. |
| `aegis.range` | Bare integer accepted at a declared constrained scalar boundary, or unchecked `@fromBackingInt` construction of Ranged; bug is invalid values surviving a discarded check or arithmetic. Domain configuration must name the inclusive bounds; no fabricated universal bounds. | `try int.Ranged(u32, 1, 1000000).init(raw)`; later operations return OutOfRange. | `safe: range: C boundary; imported ABI field is immediately converted by Ranged.init before use`. |
| `aegis.failing-cast` | Resolved narrowing/sign-changing `@intCast` or truncation of safety-relevant values, especially with runtime safety disabled. Exempt only compiler-proven widening, or documented wrapping representations. No float policy is inferred. | `try int.cast(u32, count)`; compiler rejects float sources. | `safe: failing-cast: design removes the bug class; preceding parsed length is <= maxInt(u32)`; `safe: failing-cast: safe-type internals; explicit min/max checks precede conversion`. |
| `aegis.id-domain` | Bare integer at configured ID fields/parameters; mixing independently declared domains, ID arithmetic, unchecked enum backing imports or unreviewed `.raw()` escape. Lint needs resolved declaration/configuration; suffix matching alone is not enough. Imported IDs are not authentication or global uniqueness. | `id.Id(RequestTag, u64).fromRaw(raw)`; `try id.NonZero(RecordTag, u64).fromRaw(raw)`; typed eql/compare/hash/encoding. | `safe: id-domain: OS boundary; pid is immediately branded after the syscall`; `safe: id-domain: danger absent; this integer is a loop count, not identity`. |
| `aegis.id-exhaustion` | Raw increment/wrap of an ID issuer, treating saturating increment as issuing a fresh ID, or resetting issuer state while prior IDs survive. Cross-process uniqueness remains caller policy. | Externally synchronized `try id.Counter(Tag, u64).next()`; state unchanged after IdExhausted. | `safe: id-exhaustion: design removes the bug class; rebuilding creates a new independently unique namespace`; reviewed proof required. |
| `aegis.count-domain` | Bare counters whose independent count domains can be mixed; direct Count fields or cross-tag raw conversions. No arbitrary dimensional algebra is inferred. | `units.Count(ItemTag, u32)`; typed add/sub, scalar mul, checked repr conversion. | `safe: count-domain: danger absent; local scalar is an algorithmic coefficient`; `safe: count-domain: C boundary; explicitly convert the returned count before admission`. |
| `aegis.byte-unit` | Multiplying/dividing bare lengths by eight or mixing bits/bytes through integer fields, lossy rounding hidden in casts. | `units.Bytes(u64)` / `Bits(u64)`; `try bits.toBytes()` or explicitly `.toBytesRounded(.up/.down)`; `try bytes.toBits()`. | `safe: byte-unit: safe-type internals; checked scale implements Bytes.toBits`; `safe: byte-unit: OS boundary; ABI byte extent is explicitly branded`. |
| `aegis.time-domain` | Bare `_ms`/`_ns` configured spans/timestamps, cross-clock casts/subtractions, truncating conversions or storing a persisted monotonic instant across reboot. Names alone are hints for reporting, not proof. | `Duration(.millisecond, i64)`; `Instant(.awake, .nanosecond, i128)`; explicit checked convert and sampled `correspond`; checked clock-aware std.Io adapters. Public waits retain std.Io.Timeout. | `safe: time-domain: OS boundary; std.Io.Clock.Timestamp is converted and clock checked before use`; `safe: time-domain: design removes the bug class; this wire field has a fixed seconds epoch documented by the protocol`. |
| `aegis.required-contract` | Debug-only assertion or `unreachable` used as semantic programmer validation; peer/input failure routed to fail-stop instead of errors; direct stripping of required checks. | `assert.invariant/pre/post(condition, static_public_message)` in all modes. Peer failures return named errors. | `safe: required-contract: danger absent; optional diagnostic has no semantic role and uses assert.debug`; checks required by the API cannot be suppressed for timing. |
| `aegis.possibility` | Side effects in `maybe`, `maybeCount`, or Debug predicate arguments; implication that maybe must be true or is a branch hint. Count only caller-owned test storage. | `assert.maybe(side_effect_free_condition)`; optional predicate `assert.debugCheck(predicate, context)` removes the predicate call in release. | `safe: possibility: safe-type internals; test-only caller-owned coverage counter`; no exception permits secretly required work in an erased predicate. |

Bad examples: `length * width` after unvalidated peer import; `pid == request_id`; `nanoseconds / 1000000` without declared rounding; `assert.pre(peer_length <= limit, ...)`; `maybe(sendPacket())`. Good examples: the compiled A3 region in `examples/usage.zig`, rejected mixtures in `ci/negative/`, and independent properties in `src/testing/foundations_test.zig`.

Scope capabilities, borrow annotations and checked references remain later design work. Handles are outside A3; Mason Remaley's ZCS is prior art to inspect for the future handles batch, not an A3 implementation or claimed comparison.
